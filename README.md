# Beginning PyTorch

A personal learning repository documenting my early, hands-on exploration of PyTorch and deep learning — built as Google Colab notebooks so each experiment is runnable from scratch with zero local setup.

## Notebooks

- **`day1.ipynb`** — first steps with PyTorch: checking CUDA availability, exploring `torchvision.models`, and loading a pretrained ResNet-101 to understand how large pretrained vision models are structured and used.
- **`usingNeuralTalk.ipynb`** — a deeper dive into image captioning, adapting an existing PyTorch image-captioning implementation (show-and-tell / NeuralTalk-style architecture) to generate natural-language captions for images, including setting up pretrained weights and running inference on custom uploaded images.

## Why This Repo Exists

Before building applied computer vision and deep learning projects (like my [Smart Campus Occupancy System](https://github.com/NDANGA1/cso-idss)), I used this space to build fundamentals: understanding tensors, pretrained model architectures, transfer learning, and how vision + language models like image captioners actually work end-to-end.

## Running

Each notebook has an "Open in Colab" badge — click it to run directly in Google Colab with GPU support, no local installation required.
